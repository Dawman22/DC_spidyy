# The Web Archive — Spider-Verse Fan Page

A responsive, static fan tribute page built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run:
```bash
python -m http.server 5500
```
Then visit http://localhost:5500

## Publish on GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Your site will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Add your own media
- In **The Score**, click `ADD AUDIO` and select an audio file.
- In **The Reel**, click `LOAD VIDEO` and select a video file.
- The selected files are loaded locally in your browser and are not uploaded to GitHub.

## Notes
- Gallery photos are loaded from Unsplash and require an internet connection.
- The page is an unofficial fan-made tribute and is not affiliated with or endorsed by Marvel.
- No build step or framework is required.
